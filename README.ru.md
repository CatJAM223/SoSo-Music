Ищите музыку в SoundCloud и YouTube Music, собирайте медиатеку и находите следующий трек в **«Моей волне»**. Переключайтесь между прослушиванием, караоке и игрой на гитаре в одном приложении.

[Возможности](#возможности) · [Установка](#установка) · [Быстрый старт](#быстрый-старт) · [Разработка](#разработка) · [Решение проблем](#решение-проблем)

## Возможности

- **Два музыкальных каталога.** Поиск треков, исполнителей и альбомов в SoundCloud и YouTube Music.
- **«Моя волна».** «Поток», «Бодрое», «Спокойное», «Открытия» и «Микс» учитывают лайки, пропуски и историю прослушивания. Можно выбрать одну площадку или объединить обе.
- **Своя медиатека.** Любимые треки, плейлисты, сохранённые альбомы, подписки и статистика. Перенос публичных плейлистов из Яндекс Музыки и VK Музыки с проверкой найденных совпадений.
- **Тексты и гитара.** Синхронизированное караоке, схемы аккордов, табы Songsterr и официальные клипы, когда они доступны.
- **Удобное воспроизведение.** Плавные переходы, выравнивание громкости, таймер сна, сниппеты, очередь и автоматическое восстановление после временных сбоев загрузки.
- **Офлайн.** Скачивание доступных треков и обложек. Для поиска и новых потоков по-прежнему нужен интернет.
- **Оформление под себя.** Темы, цветовые акценты, анимированный фон и видеообои. Русский и английский интерфейс с переключением в настройках.
- **Интеграция с Windows.** Медиаклавиши, трей, мини-виджет и необязательный Discord Rich Presence. Передача медиатеки в приложение на телефоне по локальной сети Wi-Fi.

## Установка

1. Откройте [GitHub Releases](https://github.com/CatJAM223/SoSo-Music/releases) и выберите ZIP для Windows x64.
2. Распакуйте **весь архив** в папку с правом записи.
3. Запустите **SoSo Music.exe** внутри папки приложения — обычно `win-unpacked`. Сохраните рядом ресурсы и DLL.

Текущая версия распространяется как переносимая сборка Windows. Если переместить только EXE, приложение не заработает. Готовые сборки публикуются отдельно от исходников, в Releases.

## Быстрый старт

- Найдите музыку и нажимайте сердечко рядом с понравившимися треками. Добавляйте плейлисты и подписывайтесь на исполнителей.
- Откройте **«Мою волну»** и нажмите шестерёнку, чтобы выбрать режим и источник музыки.
- В **Настройки → Внешний вид** переключите язык кнопками **RU / EN**. Выбор сохраняется и применяется сразу.
- Добавьте свой API key Last.fm в **Настройки → Интеграции**: там есть [ссылка на получение ключа](https://www.last.fm/api/account/create). Затем откройте **Настройки → Статистика**, чтобы проанализировать жанры. Ключ сохраняется локально и не входит в исходники, сборки или экспорт медиатеки. Этот необязательный анализ отправляет названия треков и имена исполнителей в Last.fm; любимые треки влияют на профиль сильнее. [Подробнее о музыкальном вкусе](docs/library-taste.md).
- Кнопка текста песни в плеере открывает караоке и гитару. Повторное обучение доступно в **Настройки → Внешний вид**.

Приложение восстанавливает последний трек, позицию и очередь. Прослушивание продолжается после нажатия кнопки воспроизведения.

### Аккаунты и перенос медиатеки

YouTube может потребовать вход или проверку. Подключите аккаунт в **Настройки → Интеграции**. **«Обновить сессию»** сохраняет вход и запрашивает свежие данные потока. Необязательный ключ YouTube Data API используется для поиска официальных клипов; обычное прослушивание музыки в нём не нуждается.

Для переноса медиатеки откройте **Настройки → Данные → Синхронизация** на ПК и отсканируйте QR-код в приложении на телефоне. Оба устройства должны находиться в одной локальной сети. Передаются данные медиатеки, без аудиофайлов и cookies аккаунтов. В настройках также есть экспорт и восстановление резервной копии JSON.

## Оверлей и горячие клавиши

Откройте **Настройки → Горячие клавиши**. По умолчанию **Ctrl+Shift+Space** открывает/скрывает оверлей, **Ctrl+Alt+Right/Left** переключают треки, **Ctrl+Alt+Space** ставит на паузу и продолжает. Оверлей показывает обложку, название и исполнителя на прозрачном фоне; все клики проходят насквозь. Чтобы переместить карточку, нажмите **Настроить положение** в настройках, а после перемещения — **Готово**. Положение и свои сочетания сохраняются. Для игр используйте оконный режим или окно без рамок: эксклюзивный полноэкранный режим может скрывать оверлей.

Новые стабильные релизы GitHub проверяются примерно раз в 90 секунд без перезапуска плеера. Уведомление не останавливает музыку. «Позже» скрывает уведомление об этой версии, а скачивание открывает страницу релиза. При сетевых ошибках и лимитах проверки становятся реже. Старая сборка 3.0.5 получает эту возможность только после ручного обновления.

## Разработка

### Требования

- Windows для разработки и упаковки настольного приложения.
- **Node.js 24+** и npm.
- Стабильный Rust с целью **wasm32-unknown-unknown** для локального вычислительного модуля.

```powershell
rustup target add wasm32-unknown-unknown
npm ci
npm run dev
```

Если политика PowerShell блокирует `npm.ps1`, используйте `npm.cmd`.

### Сборка

```powershell
npm run build
npm run package:zip
```

Распакованное приложение появится в `release/win-unpacked/`. Упаковка ZIP проверяет версию приложения, создаёт контрольную сумму SHA-256 и отказывается перезаписывать существующий архив.

### Проверки

| Команда                          | Что проверяет                                   |
| -------------------------------- | ----------------------------------------------- |
| `npm run lint`                   | Типы TypeScript                                 |
| `npm run format:check`           | Форматирование                                  |
| `npm run architecture:check`     | Границы main, preload и renderer                |
| `npm test`                       | Регрессионные тесты Node и подготовку Rust/WASM |
| `npm run test:desktop-ui`        | Интерфейс Electron, настройки и обучение        |
| `npm run test:player-state`      | Состояние и жизненный цикл плеера               |
| `npm run test:audio-transitions` | Реальные переходы аудио                         |
| `npm run test:ui-performance`    | Отзывчивость больших медиатек                   |
| `npm run release:check`          | Согласованность версии и метаданных релиза      |
| `npm run test:all`               | Полный набор локальных проверок                 |

Перед изменениями прочитайте [CONTRIBUTING.md](CONTRIBUTING.md). Часть проверок запускает Electron и требует рабочей сессии Windows. Результаты тестов и локальные сборки создаются в папках, исключённых из репозитория.

### CI и выпуск сборок

GitHub Actions проверяет форматирование, типы, архитектуру и регрессионные тесты при изменениях кода или конфигурации. Пустые push и изменения только документации не запускают CI; устаревшие запуски отменяются.

Workflow **Windows release** можно запустить вручную, чтобы скачать артефакт сборки. Тег, совпадающий с версией пакета, например v3.1.0, запускает сборку и публикацию GitHub Release с ZIP и контрольной суммой SHA-256. Настольное приложение не пересобирается после каждого коммита.

### Структура проекта

```text
src/desktop/main/   Сервисы Electron, SQLite и обработчики IPC
src/desktop/ui/     Экраны и компоненты Windows
src/renderer/      Точка входа renderer и общие стили
src/shared/        Логика плеера, компоненты, контракты и локализация
native/            Исходники Rust/WASM
public/            Ресурсы приложения и лицензии шрифтов
scripts/           Сборка, выпуск версий и проверки
tests/             Регрессионные тесты и фикстуры
docs/              Техническая документация
```

Стек: Electron, React, TypeScript, Vite, SQLite (sql.js), Rust/WASM и hls.js. Тексты и метаданные зависят от внешних сервисов. Если локальный вычислительный модуль недоступен, используется JavaScript.

## Решение проблем

| Симптом                          | Что попробовать                                                                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Трек ожидает загрузки            | Временные сбои повторяются автоматически с сохранением позиции. Проверьте соединение, если ожидание затянулось.                                                    |
| YouTube требует проверку         | Откройте окно аккаунта в интеграциях и завершите проверку. Если вход уже выполнен, попробуйте обновить сессию. Google может ограничивать вход во встроенных окнах. |
| Каталог не возвращает результаты | Проверьте соединение и выберите другой источник. Доступность зависит от площадки и региона.                                                                        |
| Сборка не открывается            | Распакуйте ZIP полностью и сохраните ресурсы приложения рядом с EXE.                                                                                               |
| Сборка завершается с EPERM       | Закройте процессы, использующие выходные файлы сборки, и повторите команду.                                                                                        |

[Сообщите об ошибке](https://github.com/CatJAM223/SoSo-Music/issues), указав версию приложения и Windows, шаги воспроизведения, ожидаемое поведение и подходящие строки из **Настройки → Данные → Открыть логи**. Перед отправкой удалите cookies, токены и коды сопряжения.
