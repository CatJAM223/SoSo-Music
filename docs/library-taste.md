# Жанровый профиль Last.fm

В «Настройки → Статистика» можно проанализировать все любимые треки и записи плейлистов, сохранённые в локальной медиатеке. Ограничения выборки волн (48 опорных треков, 8 записей плейлиста) здесь не применяются. Дубли одной песни объединяются между источниками и плейлистами. Дизлайки исключаются.

Для анализа добавьте свой API key в **Настройки → Интеграции → Last.fm**. [Получить ключ](https://www.last.fm/api/account/create) можно после входа в Last.fm и создания API-приложения. Нужен API key; Shared secret не используется. Ключ хранится отдельно от медиатеки в локальных настройках приложения и не включается в резервные копии JSON. Без ключа фоновый анализ не отправляет запросы; прослушивание музыки и базовая «Моя волна» продолжают работать.

Last.fm получает исполнителя и название песни. Используется [track.getTopTags](https://www.last.fm/api/show/track.getTopTags); если жанров нет, выполняется [artist.getTopTags](https://www.last.fm/api/show/artist.getTopTags). Теги преобразуются в известные музыкальные стили: произвольные пользовательские метки и годы не становятся жанрами. Содержимое аудио не скачивается и не отправляется.

Кэш хранится в SQLite. Положительные результаты обновляются через 30 дней, пустые через 7 дней. Ошибки сети не записываются как отсутствие жанра; повторный ручной запуск повторяет неудачные запросы. После трёх последовательных ошибок анализ останавливается. Результаты успешно обработанных записей сохраняются. Запросы идут последовательно с паузой. Можно остановить анализ, закрытие окна настроек его не прерывает. Остановленные записи не возобновляются автоматически в текущем сеансе; новые добавления продолжают обрабатываться. Ручной запуск возобновляет проверку всей библиотеки.

Переключатель автоматического анализа сохраняется между запусками. По умолчанию выключен. При включении обрабатываются ещё неизвестные записи; новые лайки и добавления в плейлисты запускают анализ сразу. Изменения во время текущего прохода попадут в следующий. Резервная проверка раз в 30 секунд учитывает импорт и синхронизацию. При сбое сети автоматические повторы выдерживают паузу 5 минут.

Любимый трек имеет вес 2, запись только в плейлисте 0.5; суммарный вклад одного исполнителя ограничен 6. Жанры пересекаются, поэтому исходные доли не обязаны складываться в 100%. В круговой диаграмме доли нормализуются, а округлённые проценты в легенде в сумме дают 100%. При наведении на сектор или название жанра, а также при фокусе с клавиатуры показывается точное число треков этого жанра. Один трек может учитываться в нескольких жанрах. Диаграмма размещена под основной статистикой прослушиваний. Удалённые из библиотеки записи сразу перестают влиять на профиль, хотя их кэш может использоваться при повторном добавлении.

«Моя волна» обогащает опорные треки сохранёнными тегами и учитывает жанровое распределение всей библиотеки при ранжировании. При наличии профиля каждый набор дополняется поиском конкретных песен через [tag.getTopTracks](https://www.last.fm/api/show/tag.getTopTracks). Два жанра выбираются с учётом их веса из восьми ведущих жанров и настроения волны. Для каждого ищутся до трёх разных исполнителей; недавно прослушанные песни пропускаются. Результаты YouTube Music и SoundCloud принимаются только при совпадении исполнителя и песни и проходят обычную проверку недоступных записей, превью и дизлайков. Режим избранного не расширяется этим поиском. Жанровая близость даёт до 6 баллов относительно ведущего жанра, известный отсутствующий в профиле жанр — −2, неизвестная классификация — 0. Оценка сохраняется при перестроении очереди в интерфейсе. Приоритет отрицательных реакций и ограничения повторов исполнителей сохраняются. Для части кандидатов без классификации запрашиваются теги исполнителя с коротким таймаутом. Неизвестные записи остаются допустимыми, а режим открытий и реакции слушателя сохраняют влияние.

MusiCNN, ONNX, AudioWorklet захвата фрагментов и процесс нейросети удалены. Старые таблицы аудиопризнаков в ранее созданных базах не читаются и не обновляются; медиатека не пересоздаётся.
