# SoSo Music 3.3.4

## Новое

- Эквалайзер в настройках воспроизведения: 10 частотных полос, интерактивный график и семь пресетов. При переключении пресетов кривая и звук изменяются плавно.
- Выбор региона в топ-чартах: мировой рейтинг и 19 стран. Чарты используют официальный каталог YouTube Music.
- Непрерывный анализ громкости LUFS и true peak. Уточнена нормализация, сохранена постоянная коррекция во время трека и плавные переходы.
- Вычисления «Волны», подбор при импорте и обработка офлайн TS аудио перенесены на Rust. Пересчёт очереди выполняется в отдельном Worker.

## Исправления

- Восстановлен подбор подходящей записи для недоступных YouTube треков.
- Исправлена загрузка каталога исполнителя и разделение источников: страница показывает музыку сервиса, из которого открыта.
- Улучшены жанровые подборки: фильтрация повторов, длинных миксов и неподходящих записей.
- Исправлены взаимодействие нормализации с ползунком громкости, эквалайзером, буферизацией, отключением звука и crossfade.
- Исправлен первый запуск: загрузчик занимает всё окно, сохраняет анимацию до готовности интерфейса и затем плавно исчезает.
- Исправлена подсветка кнопки караоке при наведении.

## Обновления платформы

- Electron 45, React 19, Vite 8, Tailwind CSS 4 и обновлённые библиотеки плеера.
- Обновлены проверки запуска, воспроизведения, интерфейса и фоновых ресурсов.

## Windows x64

Скачайте ZIP или 7z, распакуйте архив и запустите `win-unpacked/SoSo Music.exe`.

- `SoSo-Music-3.3.4-windows-x64.zip`
- `SoSo-Music-3.3.4-windows-x64.7z`
- Для каждого архива приложена контрольная сумма SHA-256.
