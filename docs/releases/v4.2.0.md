# SoSo Music 4.2.0

«Моя волна» и ежедневная пятёрка используют общую локальную персонализацию. Плеер передаёт меньше данных при запуске большой очереди, а оверлей автоматически уступает место главному окну.

## Скачать и запустить

Выберите ZIP или 7z. Оба архива содержат одну и ту же переносимую сборку для Windows x64. Распакуйте архив целиком и запустите **SoSo Music.exe** в корне распакованной папки. Файлы DLL и каталог `resources` должны лежать рядом с EXE. Контрольные суммы доступны в файлах `.sha256`.

## «Моя волна» и ежедневная пятёрка

- Меню **Доля новой музыки** позволяет сместить подбор в сторону знакомой музыки, оставить сбалансированный режим или чаще находить новых исполнителей. Смена настройки обновляет будущую подборку и сохраняет текущий трек и подготовленный переход.
- Плеер различает знакомую песню, новую песню знакомого исполнителя и музыку незнакомого исполнителя. Он учитывает успешные прослушивания и реакции, чтобы выбирать, когда стоит искать похожие записи, а когда попробовать другой способ поиска.
- Сигналы для персонализации сохраняются локально. Для поиска музыки продолжают использоваться каталоги выбранных сервисов.
- Ежедневная пятёрка использует те же настройки и накопленные сигналы. Уже собранные треки сохраняются на день по правилам подборки. При пополнении плеер переиспользует проверенные результаты и учитывает дизлайки, включая большие списки и альтернативные загрузки одной песни.
- Автоматический переход с кроссфейдом после перемотки к концу трека учитывается как завершение. Явный дизлайк не превращается в положительный сигнал из-за прослушивания той же записи.

## Оверлей, виджет и караоке

- Оверлей скрывается, пока главное окно плеера в фокусе. При переключении в другое приложение он возвращается, если был включён и оставался открытым. Редактор положения по-прежнему запускается из настроек.
- Караоке приостанавливает визуальные обновления в скрытом окне и восстанавливает позицию по часам аудио. Виджет получает лёгкие поправки позиции отдельно от метаданных трека.
- Стандартная тема загружает декоративные модули по мере необходимости. Для анимированных тем ограничен размер графических буферов. «Чёрная дыра» объединяет статические слои при изменении размера окна.

## Очередь, база и фоновая работа

- При запуске из медиатеки между процессами передаются только поля, необходимые для воспроизведения. Сохраняются сортировка, поиск, идентификация записей и полный порядок очереди. Быстрые повторные клики могут переиспользовать незавершённый запрос.
- Частые контрольные точки воспроизведения переиспользуют подготовленную сериализацию очереди. При выходе уже сохранённая база не записывается повторно. Несохранённые изменения по-прежнему записываются перед закрытием.
- Анализ профиля вкуса запускается при изменении медиатеки. Для Discord убрана периодическая пересылка прогресса между процессами плеера. Чтение офлайн-обложек ограничено кэшем, а запоздалый результат не подменяет обложку нового трека.

## Замеры и проверка

На синтетической библиотеке из 50 000 треков размер полезных данных очереди в JSON сократился с **9,76 до 3,61 МБ**. Медиана повторного чтения очереди через IPC уменьшилась с **452 до 329 мс**. При чистом выходе в этом сценарии плеер пропустил запись снимка базы объёмом **7,24 МБ**. Замеры относятся к указанным операциям. Короткие прогоны не подтвердили устойчивого снижения общего расхода RAM.

Прошли 1 350 автоматических тестов и проверка production-сборки в Electron, включая скрытие оверлея при фокусе и восстановление после сбоя.
