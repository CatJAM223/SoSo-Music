# История разработки

- Новое круговое управление «Моей волной», выбор режимов и сброс.
- Уточнение влияния лайков и истории, поиск ближе к музыкальным предпочтениям.
- Улучшение восстановления потоков YouTube и подготовки следующего трека.
- Анализ всех любимых треков и треков плейлистов через Last.fm: жанры, постоянный кэш и профиль для «Моей волны».

- Освобождение скрытых графических буферов и неиспользуемого аудиокэша; сокращение копирования снимка SQLite.
- [Как работает жанровый профиль Last.fm](docs/library-taste.md).

### [3.0.0]

- Пакетное сравнение песен с историей и альтернативными версиями перенесено в Rust/WASM. Unicode-разбор, правила совпадения и порядок треков сохранены; маленькие и неподдерживаемые партии используют JS. Один локальный модуль работает на Windows и Android, асинхронно загружается при запуске и имеет предел памяти 16 МиБ. При недоступности модуля остаётся рабочий JS-путь.
- Повторная нормализация одинаковых названий и исполнителей устранена ограниченным кэшем только на время синхронного подбора партии; после завершения или исключения он освобождается.

- Добавлены короткие переходы экранов и метаданных, отклик кнопок и локальный индикатор загрузки выбранного трека на Windows и Android. Повторное нажатие отменяет загрузку; текущий трек продолжается с прежней позиции. Исправлен двойной запуск при нажатии на название.
- Ускорено сохранение очереди: пустые обложки проверяются без исключений, повторные адреса проверяются один раз в пределах снимка. Проверка и очистка вложенных данных сохраняются при каждом сохранении.

- Android: исправлено продолжение после временной потери аудиофокуса, ручная пауза и отключение наушников отменяют автоматическое возобновление. Неудачное получение фокуса не пропускает трек.
- Android сохраняет небольшую контрольную точку фонового трека и позиции без потоковых ссылок; при следующем запуске она сравнивается с последним выбором в интерфейсе. Восстановление не запускает музыку автоматически.
- Исправлено зависание плавного перехода при остановке одного декодера и при загрузке через сохранившийся буфер; снятие mute применяется к обоим участникам перехода.
- Очередь волны освобождает старую прослушанную часть, сохраняя последние 30–59 элементов для возврата. Обычные плейлисты не сокращаются. Временные ссылки ограничены 128 записями, кэш длительности YouTube — 1000.
- Смена режима, остановка и закрытие волны отменяют её ожидающие запросы и поддерживаемые HTTP-транспорты. Общий запрос сохраняется, если он ещё нужен другой волне.

- Управление воспроизведением в плеере и системном уведомлении использует общие команды; поздние ответы старого запуска не меняют состояние нового трека.
- Завершение очереди и пауза отменяют ожидающий запуск; при закрытии плеера отложенное восстановление отменяется, а запоздалые ответы игнорируются.
- Режим сна «до конца трека» включается сразу и срабатывает один раз.

- Обновлена иконка приложения: белый контур кота в наушниках на тёмном фоне.
- Исправлены смещение очереди при быстрых изменениях, повторный лайк после дизлайка и перезапись медиатеки запоздавшими ответами. Дизлайк на Android обновляет обе коллекции с откатом при ошибке хранения.
- Ожидание в караоке использует прыгающие точки без подложки и одну тонкую линию, которая последовательно превращается в небольшие цифры 3–2–1 по времени воспроизведения, без увеличения индикатора.
- Убраны лишние разделители во вкладке «О приложении».

- Добавлена вкладка «О приложении» с версией, авторством, ссылкой на репозиторий и ручной проверкой стабильных релизов GitHub. При наличии новой версии доступен переход к её релизу.

- Ошибки доступа YouTube показываются одним полноэкранным предупреждением. Отказ от входа отключает треки YouTube; подключение аккаунта восстанавливает доступ.
- Добавлено обновление сессии YouTube без выхода из аккаунта; завершённый вход снимает устаревшую ошибку. Исправлен выбор аккаунтных аудиоформатов; если доступны только объединённые HLS- или MP4/WebM-потоки со звуком, выбирается самый маленький вариант. Для объединённого файла проверяется доступность CDN до начала воспроизведения; тип потока и формат отражаются в логах.
- Выравнены колонки обзора настроек и увеличен отступ перед авторством и версией.

### [2.9.6]

- Обучение использует оформление и элементы управления настроек; повторное прохождение сохраняет текущие предпочтения до завершения.
- При проверке на бота или возрастном ограничении YouTube без подключённого аккаунта появляется объяснение с переходом в «Интеграции». Отказ от подсказки запоминается отдельно для каждой причины.

- Запуск клипа не перематывает видео повторно, пока предыдущая перемотка ещё загружается; зависание контролируется по продвижению видеокадров.
- Прямые ссылки клипов подключённого аккаунта проверяются на доступность CDN до кэширования; при отказе используется запасной источник.
- Проверены переключение треков A → B → A, запоздавшие ответы и повторное открытие караоке.

- Исправлена потеря обложек YouTube Music с yt3.googleusercontent.com при переходе из Discord.
- На ПК клип снова заполняет квадрат; мобильная версия сохраняет широкую компоновку видео.
- После неудачного запуска клип один раз автоматически запрашивает свежую ссылку; ручной повтор также обновляет ссылку, а параллельные запросы объединяются.
- Команды встроенному YouTube-плееру повторяются после его готовности; обновление длительности трека не перезапускает клип.

- Ссылки Discord компактно передают названия и исходную обложку альбома; изображение совпадает с плеером.
- Поиск потока клипа использует подключённый аккаунт первым; HLS-видео поддержано в общем экране караоке.
- Ответы YouTube с описанием форматов без ссылок на поток диагностируются отдельно от ошибок расшифровки и входа.
- Исправлена передача структурированных данных о маршруте при старте воспроизведения; логи различают аккаунт, анонимный поток и локальный кэш.
- Проверены освобождение ресурсов HLS-клипа и отсутствие ссылок на поток в ответах YouTube.

### [2.9.3]

- Единая версия для Windows, Android, интерфейса и имён сборок.
- Проверка метаданных релиза, версии упакованного приложения и SHA-256 архива.
- Начато разделение IPC-модулей; добавлена проверка границ зависимостей.
- Раздельная загрузка интерфейсов Windows и Android и общий тип режима волны.
- MIT с авторством CatJAM223 и пояснение об отсутствии гарантий.
- Обновлён README; удалены отдельные устаревшие Markdown-отчёты.
- В окне входа YouTube исправлены обработка перенаправлений вложенных страниц и завершение повторного входа; реальная 2FA требует пользовательской проверки.
- Поддержаны региональные адреса входа Google; неудачная сессия аккаунта больше не блокирует доступное воспроизведение без входа.
- В логах отмечается маршрут реального воспроизведения и кэш URL; ошибки загрузки отдельного трека не помечают аккаунт неисправным.
- Подтверждение приёма медиатеки с телефона оформлено в теме приложения; завершение входа YouTube сопровождается анимацией круга и галочки.
- Исправлена потеря метода расшифровки аудиоформата при воспроизведении через аккаунт YouTube; проверки используют настоящие классы и подписанный транспорт YouTube.js.
- Восстановление HLS ограничено; зависший буфер повторно запрашивает поток, сохраняя позицию воспроизведения.
- Нативный сервис Android ограничивает время подготовки аудио; сетевой тайм-аут не считается повреждением офлайн-файла.
