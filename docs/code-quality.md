# Качество кода

Единый стиль задаёт .prettierrc.json. Команда npm run format исправляет оформление исходников, тестов и скриптов; npm run format:check проверяет его без записи. Общий запуск npm run test:all включает эту проверку. TypeScript работает в строгом режиме и запрещает неиспользуемые локальные объявления и параметры.

## Ответственность модулей

- desktop/main/index.ts связывает сервисы и регистрацию IPC. Обработчики медиатеки, плейлистов, истории и текстов находятся в отдельных файлах desktop/main/ipc.
- shared/hooks/useLyricsVideo.ts управляет поиском, загрузкой и восстановлением клипа. LyricsModal отвечает за представление текста и взаимодействие с пользователем.
- desktop/ui/hooks/useYouTubeAccountSettings.ts хранит состояние подключения, подписывается на изменения и выполняет команды аккаунта.
- shared/utils/karaokeProcessing.ts содержит очистку текста, согласование аккордов и инструментальные паузы. UI и сервис текстов используют одну реализацию.
- shared/utils/librarySearch.ts фильтрует обычные и офлайн-треки. shared/utils/playlistEvents.ts оформляет общую подписку с очисткой.
- shared/utils/boundedCache.ts сохраняет ограниченные коллекции и общий способ записи в существующие FIFO-кэши аккордов и табулатур.
- desktop/main/services/electronRuntime.ts получает Electron app для сервисов, которые также запускаются в Node-тестах.
- shared/services/waveSource.ts нормализует и сохраняет источник волны. waveCatalog ограничивает запросы провайдерам, а waveCandidatePool проверяет результаты.
- shared/utils/soundcloudPlayback.ts определяет подписочные ограничения и укороченные форматы. Определение доступности не зависит от названия группы или жанра.

## Правила изменений

Используйте имена, раскрывающие смысл данных. Выделяйте функцию по задаче и действительному повторению, сохраняя явный поток выполнения. Не добавляйте слои и расширения без текущего потребителя.

При разделении модуля сохраняйте публичные контракты, правила отмены, порядок событий и очистку ресурсов. Ошибку обрабатывает уровень, который может восстановиться или сообщить о проблеме. Допустимый отказ необязательного API должен иметь понятный запасной путь.

Тесты проверяют поведение на изолированных данных. Для загрузки участков исходника используйте TypeScript AST из tests/helpers/sourceInspection.mjs, а не номера строк или точное оформление. Мутационные проверки подтверждают, что пропуск реальной логики обнаруживается тестами.

Крупные сервисы провайдеров, база и жизненный цикл плеера продолжают содержать значительный объём логики. Изменяйте их по отдельным ответственностям с соответствующими проверками, избегая механического разбиения по числу строк.
